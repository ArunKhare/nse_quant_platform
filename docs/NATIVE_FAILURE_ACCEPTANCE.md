## Native integration

Every integration case first calls NativeAcceptanceCase.run in a disposable pytest directory:
received bytes -> Bronze -> frame/reference Silver -> association -> Gold -> bundle staging
-> current checks -> research publication -> audited point-in-time refusal -> frozen replay.
No successful source/model/reader return is substituted. All seed owners close before tests
reopen file-backed roles. Read operations use read_only=True, and writable fault-injection
owners never overlap a read-only owner for the same file. SQL names quote catalog/schema/table.
Synthetic HTTP envelopes still are contract fixtures, never authenticated provider acquisition.

The only monkeypatch is an operational final-audit write exception on the actual target
AuditLedger. Native publication reading, assessment, receipt encoding and domain writes run.
It is not a substituted source, computation, solver or successful native result.
SQL corruption cases explicitly simulate privileged damage in DISPOSABLE files. They do not
pretend to be native legitimate revisions, revocations, registrations or production recovery.

## Sanitized evidence

The QA runner loads native_failure_acceptance_report as a pytest plugin for this suite only.
It records sanitized test IDs and setup/call/teardown outcomes. No raw traceback, exception body,
credentials, local path or payload enters this JSON. A test passes only after all three phases
pass. The predeclared case inventory prevents filtered/missing tests from silently passing.
Collection failure, no tests, skipped/incomplete tests, or nonzero exit prevents suite_passed.
All six mandatory real-evidence/platform requirements remain BLOCKED, even if every test passes.
Report limit: 128 cases and 64 KiB serialized bytes. Limits are not total memory ceilings.
The report does not assert exact full environment/code/config pins or original decision replay.
An operator-reviewed HEAD is checked by the runner; a dirty worktree is printed, not certified.
Report creation is exclusive: never overwrite prior reports. Choose a new report path each run.
